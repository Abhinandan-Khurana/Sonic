# The `.vinyl` Package Specification

Runout introduces the **`.vinyl`** container format: a single, self-contained file bundle capable of transporting an entire album, its artwork, metadata, liner notes, and cryptographic checksums between devices.

---

## Package Structure

A `.vinyl` file is an uncompressed or standard DEFLATE ZIP container containing the following hierarchy:

```
album-release.vinyl (ZIP Archive)
├── manifest.json       # Structural metadata, tracklist, credits, license
├── sleeve.jpg          # High-resolution square cover art
├── checksums.json      # SHA-256 fingerprint for every included audio track
└── audio/              # Original audio files (unaltered bitstream)
    ├── 01_track_one.flac
    ├── 02_track_two.flac
    └── 03_track_three.flac
```

---

## 1. Package Types

Runout defines three discrete package types in `manifest.json`:

| Type | Audio Included | Intended Use Case |
| :--- | :---: | :--- |
| **`ALBUM`** | **Yes** | Used for Creative Commons albums (including Friday Drops) and personal original pressings ("I made this music"). Contains the complete, unaltered audio files. |
| **`CARD`** | **No** | Used when sharing commercial records. Contains the sleeve artwork, vinyl formulation, notes, and tracklist, but **no copyrighted audio**. Friends see the record on their shelf as a collectible card. |
| **`FRIEND`** | **No** | Exported identity card containing username, display name, public key, and thumbnail catalog of up to 600 records to establish friendship offline. |

```json
        ]
      }

  }

```

## 3. Cryptographic Verification (`checksums.json`)

To ensure bit-perfect audio delivery across wireless channels, every audio file is fingerprinted at the time of archive creation:

```json
{
  "audio/01_Opening.flac": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "audio/02_Lowlight.flac": "ca978112ca1bbdcafac231b39a23dc4da786eff8147c4e72b9807785afee48bb"
}
```

### Ingestion Validation Pipeline:
1. `VinylPackage.kt` unpacks the archive into a secure temporary sandbox.
2. Every file in `audio/` is streamed through a SHA-256 digest engine.
3. If any hash does not match `checksums.json` byte-for-byte, the import is aborted with an error (`"Record arrived damaged; request a resend"`).
4. Audio is never played or moved to the permanent library if corrupted.

---

## 4. Security & Hardening

1. **Zip-Slip Directory Traversal Defense:** All ZIP entry names are sanitized. Entries attempting path traversal (e.g. `../../../../system/`) or absolute filesystem paths are rejected.
2. **Path Stripping:** Local directory paths from the sender's phone are stripped prior to packing.
3. **Archive Size Quota:** Unpacked extraction has an enforced hard ceiling of 4.0 GB per `.vinyl` file to prevent archive decompression bombs.
4. **Self-Card Prevention:** Importing a friend card generated by your own private key is detected and declined.

---

## 5. The Rights Rule

To comply with Google Play Developer Policies and copyright laws:
- **Audio Travels:** Only for your own music (`"I made this music"` flag) and Creative Commons licensed records.
- **Cards Travel:** For all commercial copyrighted music found in local folders.
- This policy ensures Runout operates as a **personal player and legal trading platform**, not an illegal file-sharing service.
